# 0.2.0 part E (M4): Tools part 1 and Option Chain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Tools tab with 10 web tool pages running unchanged in Expo DOM components behind plan D's key-free bridge, their 9 session routes answered on the phone from `/api/v1` and held to the server's own Python by golden tests, a native Option Chain, and the shared market module (symbol master, expiries, futures, Black-76 in both modes, server clock, history batch) that plan F builds on.

**Architecture:**
- **Frontend source.** The pinned `frontend/src` is extracted read-only to `./openalgo/`, where CI already checks it out. Metro resolves `@/` into it, with packages from the app's `node_modules`.
- **DOM side** (`src/dom/tools/`, `src/dom/web/`): three `'use dom'` entries on one provider shell, and fetch, XHR and WebSocket shims over plan D's bridge.
- **Native side:** `src/dom/gateway/` (allowlists, startup answers, pass-through, downloads, `optionchain` adaptation, held order writes); `src/dom/routes/` (the session routes ported, typed by the web API modules); `src/market/{options,master,history}`.
- **Native Option Chain** (`src/features/optionchain/`). Greeks come per tick from the web's own `lib/optionGreeks.ts`; BUY and SELL open the M2 ticket.

**Tech Stack:** v0.1.0 + plans C and D, plus `expo-sqlite` (`npx expo install`). The DOM packages are pinned exactly to `frontend/package-lock.json` at `openalgo.ref`: Radix (checkbox, dialog, label, popover, select, slot, switch, tabs, tooltip), axios 1.20.0, class-variance-authority 0.7.1, clsx 2.1.1, cmdk 1.1.1, html2canvas-pro 1.6.6, lucide-react 0.563.0, plotly.js 3.3.1, react-plotly.js 2.6.0, react-router 8.3.0, sonner 2.0.7, tailwind-merge 3.4.0, tw-animate-css 1.4.0 and `@tailwindcss/postcss` 4.3.0. Python goldens use uv 0.11.3 and the server's own `uv.lock`.

## Global Constraints

- **Server.** Only `/api/v1` and the WebSocket proxy. Every session route a page calls is answered on the phone; none is ever sent. The DOM holds `NATIVE_KEY` (`'__native__'`), never the key, the server URL or a socket.
- **GET-only routes with `?apikey=`** (design 7.2):
  - `instruments`, at most once per IST day per exchange;
  - `portfolio/benchmarks`, only when a tool asks.
  - `sip/frequencies` and `sectorrotation/options` take no key.
  - No URL is ever logged.
- **Frontend code is read-only.** Nothing is edited or copied, except generated constants under `--check`. DOM packages equal the frontend lockfile's versions, except `react`, `react-dom`, `@tanstack/react-query` and `zustand`, which come from the app.
- **Branch and commits.** Work on `phase1/v0.2.0` after plans C and D. Commit, never push. Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **No local native builds** (no `expo prebuild`, gradle or xcodebuild). Maestro runs only in CI.
- **Colours.** BUY is green `tokens.trade[scheme].buy` (`#00a63e`) and SELL is red `.sell` (`#e7000b`) on every native button, leg and sheet.
- **Budgets** (5% growth per PR; T14 rebaselines):
  - Hermes `android`/`ios` 6,000,000 bytes; chart DOM 2,330,000;
  - **every tool DOM page 1,900,000 bytes of JS**.
- **Request budgets** (design 12; feasibility):

  | Tool | First load | Refresh |
  |---|---|---|
  | OI Tracker, OI Range, Max Pain | 4 (expiry, `optionchain` 23, expiry futures, quotes) | 2 |
  | IV Smile | 2 (expiry, `optionchain` 25) | 1 every 30 s |
  | GEX | 4 (`optionchain` 45) | 2 every 30 s |
  | Gamma Density | 2 (`optionchain` 23) | 1 every 60 s |
  | Option Chain | 2 (expiry, `optionchain`) | live feed: 1 every 30 s; polling: 1 every 5 s (home) or 10 s (tunnel) |

  - Hidden screens make no calls. Option Chain holds at most 103 WebSocket symbols.
- **Order safety** (design 7.10 and the M2 rulings) binds held tool writes:
  - a review first; the mode re-read before the send; biometrics when `confirmLiveWrites` is on and the mode is live;
  - `useSubmitGuard`; the `NEW_ORDER` pending scope and a book snapshot, as the ticket; sent once, never retried;
  - `MaybePlaced` and `no_id` are reconciled, never re-sent.
- **Golden parity.** Rounded fields match exactly; tolerances only where a task names them. Python `round` is `pyRound`, Python `sum()` of floats is `pySum`.
- **Real test server.** Only through controller scripts in market hours (09:15–15:30 IST); nothing prints the key.
- **testIDs** are the Maestro contract (`e2e/README.md`; `{X}` parts are `[A-Z0-9&_-]`). "→ FAIL" means the module is missing. "→ PASS" means every test in the command passes.

## Review Focus

1. **Expiry day after the cut-off, or an expired chain.** Expected: every spot-mode leg is `null` (the server's "Option has expired"), so GEX gamma is 0 and IV Smile shows nulls. Nothing is clamped to the 1e-4 floor; `serverYears` is 0 after the cut-off. Test: T6 **(RF 1)**.
2. **The server is reloading its symbol table** (the first broker login of the day): the instruments CSV is empty, short or a text error. Expected: it is never stored as today's master. Yesterday's master (or the web defaults) still answers, and a retry comes after 15 min. Test: T7 **(RF 2)**.
3. **Option Chain: a fast expiry switch, then hidden or backgrounded, or in polling mode.** Expected: only the selected expiry's reply renders, no `optionchain` call goes out while hidden, and refreshes keep the budget table's rates. Test: T13 **(RF 3)**.
4. **A server older than 2.0.2.0** (no `expiry_ts`, `server_ts` or `with_greeks`) **and a phone clock 3 min off.** Expected: the chain and the routes derive the expiry from `DDMMMYY` plus the cut-off, and correct the clock from the HTTP `Date` header. Greeks still show. Test: T3, T13 **(RF 4)**.
5. **The user leaves a tool with a 120 s backtest or a held order pending.** Expected: the request is aborted, and an unconfirmed held order is answered "cancelled" and never sent later. On return, at most one call per distinct request. Test: T12 **(RF 5)**.
